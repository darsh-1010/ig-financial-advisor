# I.G. Financial Advisor

Static website for I.G. Financial Advisor, Prahlad Nagar, Ahmedabad.

- `index.html` — the whole site (HTML, CSS, JS)
- `logo.png` — logo, also used as favicon

Uses GSAP, Lenis and Three.js from CDNs, so it needs internet. To preview: open `index.html` in a browser, or run `python3 -m http.server` in this folder.
